# Re:Bind · 제조 공정과 거래명세서

제본소가 만드는 것을 공정 단위로 기록하고, 고객사 담당자는 링크만 열어
지금 어디까지 갔는지 봅니다. 공정이 끝나면 그동안 쌓인 숫자가 그대로
거래명세서가 됩니다. 다시 입력하지 않습니다.

설치 없이 브라우저에서 씁니다. **Re:Call 과 같은 회사 코드·아이디로 들어옵니다.**

**앱 — https://rebind.dnalabs.kr/**

## 하는 일

- **프로젝트 카드** — 프로젝트명·수량·규격·색상·용지·제본 방식·후가공, 그 밖의 옵션도 자유롭게
- **공정 타임라인** — 인쇄부터 출고까지 한 줄씩. 공정명과 "전체에서 몇 %" 를 함께 남깁니다.
  제본소에서 흔한 순서(입고 5% → 인쇄 32% → 제본 80% → 출고 100%)는 눌러서 채웁니다
- **알아서 바뀌는 상태** — 첫 기록이 올라가면 진행 중, 100% 가 되면 완료로 바뀌고 납품일이 찍힙니다
- **고객사 공개 링크** — 로그인 없이 그 프로젝트 하나만. 진행도·일자별 공정·사양·완성 사진·금액이 보이고,
  내부 메모와 다른 프로젝트는 보이지 않습니다. 화면은 저절로 새로 고쳐집니다
- **거래명세서** — 공급자/공급받는자, 품목, 단가, 총 제작수량, 공급가액, 부가세, 합계, 총 소요일, 완성 사진.
  **PDF(인쇄) · 엑셀(.xlsx) · 링크** 셋 중 편한 것으로
- **현황** — 납기가 지난 건, 이번 주 납기, 최근 이레의 공정 기록

## 어디에 얹혀 있나

Re:Call(고객관리)과 **같은 Supabase 프로젝트, 같은 계정**을 씁니다.
회사 격리·담당자 규칙도 Re:Call 이 쓰던 것을 그대로 씁니다. 계정을 따로 만들지 않습니다.

```
Re:Call  network-dna.html   고객 · 명함 · 미팅 타임라인
Re:Bind  bindery.html       프로젝트 · 공정 · 거래명세서
              └── 같은 데이터베이스 · 같은 로그인
```
